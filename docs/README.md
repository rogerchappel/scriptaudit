# ScriptAudit Docs

- `PRD.md` captures product requirements from the OSS factory run.
- `TASKS.md` tracks implemented V1 work and follow-up backlog.
- `ORCHESTRATION.md` describes agent usage and local verification.
- `orchestration.json` gives machine-readable factory metadata.

Generated audit reports can be written here with `scriptaudit scan . --out docs/SCRIPTS.md`.
